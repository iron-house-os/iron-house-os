# Build 217 — Employee Onboarding

Tracks implementation for issue #162 on branch `feature/162-employee-onboarding`.

## Scope

- Controlled field and office employment levels
- Admin onboarding dashboard and employee creation
- Secure, expiring, revocable portal invitations
- Employee self-service onboarding progress and submission
- Review, correction, approval, and activation workflow
- Role-based access and audit history

## Approval gate

Staging review is required before production email delivery or employee activation is enabled. Payroll, banking, tax, identity, and emergency-contact data must remain restricted to authorized roles.
