# Build 217 release gate

Do not enable production invitation emails or employee activation until all of the following are evidenced:

1. Staging database migration completed successfully.
2. Outbound email sender and portal base URL are approved.
3. Role-based access to sensitive employee data is verified.
4. Invitation expiry, resend, revocation, and single-use behaviour pass.
5. Desktop and iPad/WebKit onboarding paths pass.
6. Management approves the onboarding templates and production release.
